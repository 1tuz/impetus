# v0.1 baseline: native preview

Дата измерения: 2026-08-25.

## Окружение

- MacBook Pro `Mac17,8`, Apple M5 Pro, 48 GB RAM.
- macOS 26.4 (`25E246`).
- Rust 1.98.0.
- Debug build; GPUI-CE commit `9949f8b2d27bb1d6dbc1efe90be039634cf1fb6b` с `font-kit` и `runtime_shaders`.
- Один native window с theme preview; PTY, agent stream и SSH отсутствуют на этапе v0.1.

Серийный номер, hardware UUID и другие идентификаторы устройства в benchmark не записываются.

## Сценарий

1. Собрать приложение: `cargo build -p agentic-terminal-app`.
2. Создать отдельный временный каталог и запустить приложение с `AGENTIC_TERMINAL_DATA_DIR=<temp-dir>`.
3. Убедиться, что окно открылось, text system активен, а в каталоге появились `events.sqlite3`, WAL и SHM.
4. После прогрева снять пять RSS samples процесса с интервалом одна секунда.
5. Завершить приложение и удалить временный каталог.

## Результат

RSS samples, KiB: `83584, 83584, 83584, 83584, 83584`.

- Медиана idle RSS: **83 584 KiB ≈ 81.6 MiB**.
- SQLite/WAL/SHM созданы в изолированном data directory.
- Предупреждение `compiled without the font-kit feature` устранено добавлением `font-kit` к pinned `gpui_platform`; остались только сообщения о пропуске дубликатов системных шрифтов.
- Сборка сообщает future-incompatibility warning транзитивного `block 0.1.6`; ошибок workspace check/clippy нет.

## Интерпретация

Это baseline, а не доказательство memory budget терминала. Gate v0.2 сравнивает 30-минутный PTY soak именно с этой методикой: total RSS ≤ baseline + 128 MiB, рост между 5-й и 30-й минутами ≤ 32 MiB, hot scrollback ≤ 8 MiB на tab.

Запуск подтверждён на указанном Mac. Критерий «чистый Mac» остаётся отдельным reproducible smoke и не считается выполненным этим измерением.
