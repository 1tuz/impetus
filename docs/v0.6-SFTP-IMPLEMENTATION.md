## Implementation

### 1. SFTP Module Structure

**File:** `crates/impetus-core/src/remote/sftp.rs`

Created complete SFTP module with:
- `SftpSession`: connection lifecycle (connect, disconnect, is_connected)
- `SftpOperation`: Read, Write, Delete, List
- `SftpOperationRequest`: policy-checked SFTP operations
- `SftpResult`: typed operation results
- `SftpSessionManager`: coordinates SSH, policy, and execution
- `SftpFileInfo`: file metadata for list operations

### 2. Policy Integration

SFTP operations go through the standard effect seam:

```rust
pub fn request(&self, seam: &EffectSeam) -> Result<EffectAdmission, SftpError> {
    let effect = NormalizedEffect {
        origin: self.origin,
        capability: EffectCapability::NetworkConnect,
        version: CapabilityVersion::V1,
        action: Action {
            origin: self.origin,
            kind: ActionKind::SftpTransfer,
            summary: format!("SFTP {} on {}@{}:{}", ...),
            target: Some(format!("{}@{}:{}", ...)),
        },
    };
    Ok(seam.request(effect, self.intent_revision))
}
```

- Uses `NetworkConnect` capability (already expanded to accept `SftpTransfer` in sandbox admit)
- `ActionKind::SftpTransfer` для policy decisions
- Agent-origin operations require approval
- User-origin operations may be allowed or require approval based on policy

### 3. Admission Token Integration

Following A1 pattern, `execute()` requires `AdmittedOperation`:

```rust
pub fn execute(&self, _admission: &AdmittedOperation) -> Result<SftpResult, SftpError>
```

No SFTP operation can execute without first obtaining admission via `request()`.

### 4. SSH Profile Integration

SFTP operations use existing `SSHProfile` struct:
- Host, port, user from profile
- Host-key verification (existing SSH approval flow)
- Keychain SSH key reference (no raw keys)

### 5. Convenience Wrapper

`SftpSessionManager::execute_with_admission()`:

```rust
pub fn execute_with_admission(&self, req: &SftpOperationRequest) -> Result<SftpResult, SftpError> {
    let admission = self.request(req)?;
    match admission {
        EffectAdmission::Allow(token) => self.execute(req, &token),
        EffectAdmission::NeedsApproval(_) => Err(SftpError::ApprovalRequired),
        EffectAdmission::Deny { reason } => Err(SftpError::PolicyDenied(reason)),
    }
}
```

Enforces correct request → admission → execute flow.
