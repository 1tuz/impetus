# Impetus next-step prompt pack

Этот каталог подготовлен для делегирования coding-агенту.

- Начать с `00_RUN_ALL_IN_ORDER.md`.
- Каждый numbered prompt — независимый GitHub Issue/branch/PR.
- Следующий prompt начинается только после merge предыдущего.
- Если gap уже реально закрыт в свежем `main`, не создавать дублирующий issue.
- Весь workflow рассчитан на GitHub Issue → branch → Pull Request → GitHub Actions → auto-merge.
